# 스크롤로 조절하는 3D 모션

2026-10-19. 평면 이미지의 확대·이동 연출을 여러 부품으로 구성한 Three.js 장면으로 교체했다. 동영상을 자동 재생하거나 토스의 영상·브랜드 에셋을 복제하지 않는다. 각 물체의 위치·회전·투명도를 스크롤 진행률로 계산하므로 스크롤을 멈추면 자세를 유지하고 역방향에서도 같은 상태를 복원한다.

## 구성

| 장면 | 개별 Mesh 수 | 움직임 |
| --- | ---: | --- |
| 디지털 포렌식 | 96 | 나사가 회전하며 떠오름 → 덮개 열림 → 회로판과 칩 분리 → 렌즈 이동과 스캔 |
| Android 보안 | 55 | 디스플레이 분리 → 투명 층 전개 → 칩 상승 → 로봇 팔·머리 반응 |
| 리버스 엔지니어링 | 90 | 금속 덮개 상승 → 유리·다이·패키지 분리 → 내부 타일 전개 |

선과 그룹은 Mesh 수에 포함하지 않는다. 부품 수는 브라우저에서 실제 모델 트리를 순회해 확인했다. 물체는 재질·광원·반사·그림자를 갖는 코드 기반 모델이다.

## 동작과 파일

- `components/InterestScenes.jsx`: sticky 영역의 스크롤 진행률, 현재 장면 표시, 프로젝트 링크.
- `components/SceneCanvas.jsx`: 가까운 장면의 지연 로딩, 마우스 입력, 정적 대체 이미지.
- `components/interest-3d-runtime.js`: 카메라, 조명, 그림자, 렌더링·자원 해제, Raycaster를 통한 부품 감지.
- `components/interest-models.js`: 세 물체의 부품과 진행률별 위치·회전.
- `lib/scene-motion.mjs`: 0~240의 자세 번호, 단계별 smoothstep 곡선. 시간에 따른 자동 진행은 없다.
- `tests/scene-motion.test.mjs`: 정·역방향 동일 자세 복원, 정지, 단계 순서, 입력 범위 검증.

마우스는 장면 전체를 작게 기울이고 가리킨 부품을 2.5% 확대한다. 포인터가 벗어나면 원래 상태로 복귀한다. 터치는 스크롤을 가로채지 않는다.

렌더 해상도는 devicePixelRatio 1.5로 제한한다. 화면 밖·숨겨진 탭에서는 GPU 렌더링을 건너뛰고, 화면 안에서도 자세·포인터·화면 크기가 같으면 다시 그리지 않는다. 해제 시 geometry, material, texture, WebGL context와 observer를 정리한다. WebGL 초기화 실패 시 기존 컨셉 이미지가 남는다. 동작 줄이기에서는 마우스 효과와 스크롤 재생을 생략한다.

Auth.js, MongoDB, 관리자 동기화, Vercel Cron, 아카이브 데이터는 변경하지 않았다.

# 홈 이미지 시퀀스

2026-10-19: 홈의 실시간 Three.js 장면을 사진풍 합성 이미지 시퀀스로 교체했다.

## 구성
- 포렌식, Android, 리버싱, Web3, 퍼징 각 240프레임. PC 1,280×832, 모바일 640×832로 각각 제작해 총 2,400장의 WebP를 제공한다.
- 이미지 생성 도구로 만든 금속·유리·전자 부품 컷아웃을 고정된 모양으로 유지하며 이동·회전·분리한다. 모든 프레임을 독립 생성해 물체가 변형되는 방식이나 단순 이미지 크로스페이드는 사용하지 않는다.
- `lib/image-sequence.mjs`의 동일한 레이아웃을 오프라인 합성과 화면의 설명 카드 판정에 사용한다. 스크롤을 멈추면 해당 프레임을 유지하고 역방향 스크롤에서도 동일한 프레임을 복원한다.
- 배경은 별도의 새 스튜디오 이미지이며 과거의 컨셉 이미지는 홈에서 사용하지 않는다. 로딩 중 포스터도 새 시퀀스의 0번 프레임이다.
- 이 이미지는 실제 장비 사진이나 정확한 실측 CAD가 아닌 분야 소개용 합성 시각화다. 평면 레이어를 합성한 결과이므로 관찰 각도를 자유롭게 돌리거나 실시간 굴절을 계산하지 않는다.

## 로딩과 접근성
- 화면 근처의 장면만 초기화하고 네 개의 동시 요청으로 프레임을 점진적으로 로드한다. 현재 프레임과 이웃 프레임을 우선 처리한다.
- RGBA 디코딩 캐시는 장면당 8개로 제한하고 화면 밖에서는 2개로 축소한다. 종료 시 ImageBitmap, fetch, observer, RAF를 해제한다.
- 낮은 데이터 모드/2G에서는 전체 선로딩을 생략한다. 동작 줄이기에서는 첫 프레임만 불러온다.
- 카드 근접 영역·연결선·키보드 포커스·명시적 열기 버튼과 기존 링크를 유지한다. 모바일 화면 폭이 변경되면 해당 구도로 다시 초기화한다.
- 2D Canvas/ImageBitmap이 불가능해도 새 정적 포스터와 기록 보기 링크가 남는다.

## 재생성
`npm ci` 후 `npm run render:sequences`를 실행한다. 일부 장면만 재생성하려면 `node scripts/build-sequences.mjs forensics`처럼 지정한다. 원본 아틀라스는 `public/images/sequence-sources`에 있으며 생성 자산의 SHA-256과 프레임 수·장면별 크기는 `public/sequences/studio-raster-v2/manifest.json`에 기록했다. 공개 캐시는 버전 디렉터리 단위이므로 운영 자산을 수정할 때는 버전 이름도 변경해야 한다.

홈은 더 이상 SceneCanvas, interest-3d-runtime, interest-models를 로드하지 않는다. 이전 3D 소스와 관련 검사는 이력 보존용이며 현재 표시 방식은 위 시퀀스다. 인증·MongoDB·관리자·동기화·프로젝트·아카이브는 수정하지 않았다.

# 프로젝트 설명의 출처와 분류

2026-10-19 사용자 요청: 진행·학습 중인 여섯 프로젝트를 Projects에, 완료한 프로젝트·대회·개별 학습 기록을 Archive에 배치한다. 현재 작업의 완료를 임의로 선언하지 않는다.

| 항목 | 설명에 사용한 자료 |
| --- | --- |
| 디지털 포렌식 | 본인의 [Dreamhack 입문 글](https://iljae627.github.io/posts/dreamhack-forensics-pass/), [DFC 2026 풀이](https://iljae627.github.io/posts/DFC2026/), [Who Stole My Storage](https://iljae627.github.io/posts/dfc-2-2026/) |
| Android | [HexTree](https://iljae627.github.io/posts/hextree-android-track/), [MASTG](https://iljae627.github.io/posts/mastg-hacking-playground-24/), [Allsafe](https://iljae627.github.io/posts/allsafe-android-writeup/) |
| DS/3DS | [공개 저장소](https://github.com/iljae627/DS-3DS_-private_distribution_server), 로컬 최신 README의 세대별 구현·검증 상태, 기존 manatails 참고 글 |
| 주식 자동매매 | 로컬 프로젝트 최신 README의 Python/React 구성, 관찰·모의·실거래 분리, 주문 추적·복구·보고서 설명. 실제 금융 거래나 계좌 접근은 수행하지 않음 |
| 팬게임 제작 툴 | 로컬 최신 README와 package.json의 React·TypeScript·Phaser·Three.js 구성, 맵 편집·충돌·워프·폴더/ZIP 저장. 완성된 게임 또는 전투 시스템으로 표시하지 않음 |
| RNG-Maker | 사용자가 지정한 진행 중인 학습 주제. 공개 실험 결과가 없어 상세 과정을 학습 방향과 다음 단계로 표시하고 도구 버전·지원 기능·실기 성공을 단정하지 않음 |
| Collector | 사용자의 직접 설명: 동아리 여름방학 npm 공격 검증 도구 팀 프로젝트, Sigstore·Rekor 수집기 담당, 이후 대부분 공동 작업. [공개 저장소](https://github.com/iljae627/Collector)는 조회 당시 README 제목만 포함 |

공개 링크가 없는 로컬 개발 프로젝트에 임의의 저장소나 실적 링크를 붙이지 않았다. 개인 프로젝트의 소스·키·계좌 정보·로컬 경로는 페이지에 게시하지 않는다. 진행·완료 분류와 Collector 역할은 사용자가 제공한 설명을 우선한다.

Collector 아카이브의 날짜는 기록 정리일이며 활동 시기의 정확한 날짜는 확인되지 않았다. 활동 시기는 제목과 상세에 여름방학으로 표기한다. 수집기의 구체적 API·데이터 스키마나 공격 탐지 성능은 자료가 없어 추가하지 않았다.
